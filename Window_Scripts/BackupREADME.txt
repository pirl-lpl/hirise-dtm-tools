In order to use this script I would suggest placing the script somewhere where it can be readily
available like the desktop on your machine, from there just drag and drop the Backup.py file into a command window and press enter.
it will then prompt you for the name of your project which you can grab from socet set and it will make the backup folder in your data directory.
Once you've run it once you should just be able to use the [up] arrow key in order to run the script quickly again and pressing [up] when it prompts 
you for your project name should return the name you input before so no need to worry about re copying the project name.
Email me if you have any questions or run into any problems.
